# API Universo dos Jogos 🎮

Uma API RESTful projetada para gerenciar um catálogo de jogos e seus personagens icônicos. Este repositório foca no design do contrato OpenAPI e na automação de processos via CI/CD.

## 🚀 Endpoints Disponíveis
* `GET /jogos` - Lista todos os jogos.
* `POST /jogos` - Cadastra um novo jogo.
* `GET /jogos/{id}` - Busca os detalhes de um jogo específico.
* `GET /personagens` - Lista os personagens cadastrados.
* `POST /personagens` - Cadastra um novo personagem e o vincula a um jogo.
